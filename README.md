# Аромадиффузор 3004 Mini — ESPHome

Прямое BLE-подключение к диффузору на ESP32 DevKit без Bluetooth Proxy. Возможности: питание, RGB-подсветка, автосмена цветов, три уровня яркости, настраиваемый цикл, расчёт расхода жидкости. Конфигурация рассчитана на ESPHome 2026.10.1, ESP-IDF и `esp32dev`.

## Установка в ESPHome

1. Сохраните копию текущей конфигурации устройства. Откройте ESPHome Builder в Home Assistant, создайте устройство или откройте существующее и используйте `3004-mini.yaml`.
2. Добавьте в существующий `/config/esphome/secrets.yaml` данные Wi-Fi и BLE-адрес вашего диффузора (не заменяйте другие существующие секреты):

   ```yaml
   wifi_ssid: "Название Wi-Fi"
   wifi_password: "Пароль Wi-Fi"
   diffuser_mac: "AA:BB:CC:DD:EE:FF"  # ваш адрес из nRF Connect
   ```

   Адрес намеренно удалён из публичной копии. Для личного устройства укажите его настоящий BLE-адрес. Пример также находится в `secrets.example.yaml`. Не публикуйте `secrets.yaml`.
3. Проверьте имя устройства и сохраните индивидуальные параметры API, OTA и Wi-Fi из старого YAML. Данный пример не включает шифрование API и пароль OTA. Настройте их согласно вашей сети перед использованием.
4. Выберите **Install** в ESPHome Builder. Для существующей платы доступна установка по Wi-Fi; для новой может потребоваться USB-прошивка. После подключения добавьте устройство через интеграцию ESPHome в Home Assistant.
5. Отключите Fragrant Pro / nRF Connect от диффузора и проверьте объект «BLE соединение». Измените настройки ресурса, затем проверьте питание и подсветку.

## Управление

- Питание управляет диффузором; оно отображает последнюю команду ESPHome, а не подтверждённое состояние прибора.
- Подсветка RGB выбирает цвет. Отдельный ползунок «Яркость подсветки» задаёт уровни 1–3; штатный ползунок 0–100% RGB-света уровень не задаёт.
- «Автосмена цветов» запускает встроенный режим диффузора. При выключении света сначала отключается автосмена и спустя около секунды свет.
- Для цикла задайте время распыления Run и время паузы Pause в секундах и нажмите «Применить цикл распыления».
- «Ресурс заправки» — оценка времени фактического распыления в часах на одну заправку. После заправки нажмите «Сброс после заправки». Значение 0 означает, что лимит не задан.
- Объект «Жидкость предположительно закончилась» сообщает о расчётном исчерпании ресурса. Чтобы получить уведомление на телефон, создайте автоматизацию Home Assistant самостоятельно.

**Ограничения:** расход считается как время включения × Run / (Run + Pause), а не измеряется. Введённые Run и Pause влияют на расчёт до отправки настроек прибору. При разрыве BLE счётчик останавливается; при управлении с телефона, ошибке отправки и перезапуске состояния могут расходиться. Питание и данные счётчика сохраняются во flash периодически (до 5 минут). Не используйте оценку как защиту от работы без жидкости. Проверка BLE перед отправкой не гарантирует доставку. Если связь отсутствовала, повторно задайте настройки вручную.

## Создать публичный репозиторий GitHub

Архив подготовлен для создания **публичного** репозитория: весь его код и Git-автор будут видны всем. BLE-адрес и пароли вынесены в `secrets.yaml`, который не включён в комплект и указан в `.gitignore`. Перед публикацией проверьте все файлы: `.gitignore` не защищает данные, уже помещённые в историю Git или в другие файлы.

1. Распакуйте архив в отдельную папку на своём компьютере.
2. Установите [Git](https://git-scm.com/downloads), [GitHub CLI](https://cli.github.com/) и Python 3.
3. Откройте терминал в распакованной папке. Войдите в GitHub:

   ```sh
   gh auth login
   ```

4. Если Git ещё не настроен, задайте имя и адрес автора. Для приватности используйте GitHub `noreply`-адрес из настроек GitHub → Emails:

   ```sh
   git config --global user.name "Ваше имя или псевдоним"
   git config --global user.email "ВАШ_NOREPLY_EMAIL"
   ```

   Настройка действует для всех репозиториев данного пользователя на компьютере. Имя и email автора войдут в публичную историю.
5. Запустите `python upload.py` (на Windows при необходимости `py upload.py`; на macOS/Linux — `python3 upload.py`). Введите название репозитория или нажмите Enter для `esp32-3004-mini`.
6. Скрипт покажет список файлов и попросит явно ввести `PUBLIC`. После этого создаст локальный Git-репозиторий, коммит и публичный репозиторий в аккаунте GitHub, выполнит push и покажет ссылку. Учётные данные не передаются автору комплекта.

### Если загрузка прервалась

Проверьте, появился ли новый репозиторий в GitHub и есть ли каталог `.git` в распакованной папке. Скрипт не запускается повторно поверх существующего `.git`, чтобы ничего не перезаписать. Если репозиторий создан и `origin` настроен, проверьте `git remote -v`, затем при необходимости выполните `git push -u origin main`. Если не уверены в состоянии, сохраните вывод ошибки и уточните до повторной попытки.

## Проверка

Исходный YAML полностью собран в ESPHome 2026.10.1. Здесь адрес заменён на `!secret diffuser_mac`; перед сборкой необходимо указать реальный адрес в secrets.yaml. Реальную работу конкретного устройства и предупреждения необходимо проверить после установки.
